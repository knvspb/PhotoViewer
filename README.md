# PhotoViewer

Слайд-шоу по набору папок и карта фотографий с геометками. Всё в одном файле `index.html`, работает в браузере.
Фотографии читаются прямо с диска и никуда не загружаются.

## Возможности

**Папки**
- Можно добавить несколько папок: кнопкой (по одной) или перетащив сразу несколько из Проводника.
- Флажок у папки определяет, участвует ли она в показе. Порядок папок меняется кнопками ↑/↓.
- Список папок и доступ к ним сохраняются между сеансами (IndexedDB). Chrome может переспросить разрешение — тогда нажмите 🔓.

**Слайд-шоу**
- *По порядку*: папки идут в порядке списка; внутри папки сначала файлы, потом подпапки; имена сравниваются «естественно» (`IMG_2` < `IMG_10`).
- *Полностью случайно*: перемешивание без повторов; на каждом круге — новое.
- *По порядку со случайным шагом (в среднем N)*: идём по списку вперёд, перескакивая через случайное число файлов. Шаг равномерно распределён на 1…2N−1, поэтому в среднем равен N (например 1, 10, 15, 23, 26…). Дойдя до конца списка, начинаем новый проход по ещё не показанным, и так пока не покажутся все. Затем начинается новый цикл. Внутри прохода хронология сохраняется. Последние проходы получаются короткими, потому что каждый берёт примерно 1/N от оставшегося.
- Клавиши: `←/→` (или клик / колесо мыши), `Пробел` — пауза, `+/−` — интервал, `I` — подпись, `G` — мини-карта, `M` — прервать показ и перейти к большой карте, `F` — полный экран, `Esc` — выход.

**Карта**
- «Найти фото с геометками» читает EXIF GPS. Результат кэшируется по ключу «путь + размер + дата изменения», поэтому повторное сканирование быстрое.
- Маркеры показывают миниатюры (встроенные в EXIF, если есть) и группируются в кластеры. Подложки: OpenStreetMap, OpenTopoMap, спутник Esri.
- Карточка фото: «🔍 Открыть» и «▶ Слайд-шоу отсюда» — показ всего набора, начиная с выбранного фото, в текущем режиме.
- Во время показа: `G` — мини-карта, которая следует за текущим кадром; «Перейти к карте» прерывает показ, открывает карту на текущем фото, а там можно выбрать другое фото и продолжить с него.

## Запуск

Нужен **Chrome или Edge**: им нужен [File System Access API](https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker). В Firefox работает только «совместимый режим»: папку надо выбирать при каждом открытии.

Варианты:
1. GitHub Pages: включите в Settings → Pages (ветка `main`, корень) и откройте `https://<user>.github.io/photoviewer/`. Файлы при этом всё равно не покидают компьютер.
2. Локально: `python -m http.server 8000` в папке репозитория, затем откройте `http://localhost:8000/`.
3. Двойной клик по `index.html` (`file://`) тоже должен работать в Chrome/Edge, но этот вариант менее проверен (см. ниже).

Нужен интернет: библиотеки (Leaflet 1.9.4, Leaflet.markercluster 1.5.3, exifr 7.1.3) и тайлы карты грузятся с CDN.

## Ограничения

- HEIC/HEIF (iPhone): браузеры на Windows не умеют их показывать, поэтому слайд-шоу такие файлы пропускает. Геометки из них при этом читаются и на карте видны.
- Сортировка `Intl.Collator({numeric:true})` близка к сортировке Проводника (`StrCmpLogicalW`), но не идентична ей в экзотических случаях.
- Тайлы OpenStreetMap подчиняются [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/). Браузер со страницы `file://` не отправляет заголовок Referer, и OSM может такие запросы ограничивать. В таком случае используйте вариант 1 или 2 либо другую подложку.
