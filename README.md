# letseetheworld PhotoViewer

Слайд-шоу и галерея по набору папок (включая RAW) и карта фотографий с геометками. Всё в одном файле `index.html`, работает в браузере.
Фотографии читаются прямо с диска и никуда не загружаются.

## Возможности

**Папки**
- Можно добавить несколько папок: кнопкой (по одной) или перетащив сразу несколько из Проводника.
- **Дерево папок**: ▸ раскрывает подпапки (они читаются по мере раскрытия). Флажок у любой папки включает или выключает её вместе со всем содержимым для слайд-шоу и для карты. Если внутри что-то выключено, флажок «полуотмечен». Порядок корневых папок меняется кнопками ↑/↓.
- Щелчок по имени выбирает папку. Рядом появляется ▶, который сразу запускает слайд-шоу только по ней.
- Список папок и доступ к ним сохраняются между сеансами (IndexedDB). Chrome может переспросить разрешение — тогда нажмите 🔓.

**Яндекс.Диск** (только чтение)
- Кнопка «+ Я.Диск» → вход в Яндекс → выбор папки на Диске. Папка добавляется в дерево наравне с локальными: флажки, подпапки, слайд-шоу, галерея, карта, фильтры. Работает и в браузерах без File System Access API (Firefox), список сохраняется между сеансами.
- Вход нужен **в каждом браузере**, где открываете PhotoViewer. Токен хранится только в этом браузере (localStorage), доступ — только на чтение (`cloud_api:disk.read`). Отозвать: Яндекс ID → «Данные и доступы» (или кнопка «Выйти из Яндекса» в окне Диска).
- Если автоматический вход не сработал (например, страница открыта не с `knvspb.github.io/PhotoViewer/`) — в окне есть ручной способ: открыть страницу Яндекса, скопировать токен и вставить.
- Дата и геометка берутся из данных, которые возвращает сам Яндекс (поле `exif`), — карта строится без скачивания файлов. Миниатюры — из превью Яндекса. Оригиналы скачиваются по мере показа. Модели камеры в API Диска нет, поэтому в фильтре по камерам фото с Диска попадают в «нет данных о камере».
- «Проверить подключение» в окне Диска пошагово проверяет вход, список файлов, превью и скачивание.

**Слайд-шоу — что показывать**
- *Отмеченные папки* — с учётом флажков в дереве.
- *Выбранную папку* — вместе с подпапками. Флажки внутри неё учитываются, а её собственный флажок и флажки выше нет: можно показать папку, выключенную из общего показа.
- *Фото, видимые сейчас на карте* — только фото с геометками в текущих границах карты, в порядке имён.
- *Все фото всех папок* — флажки не учитываются.

**Сортировка**: по имени (папки → файлы) или по дате съёмки из EXIF, по возрастанию или убыванию. Фото без даты — в конце.

**★ Избранное**
- «▦ Галерея избранного» — отдельная галерея только из избранного; в любой галерее есть переключатель «☆ только избранное».
- Отметить: `L` или ☆ в просмотре, звезда на плитке галереи, ☆ в карточке на карте. Набор «★» в выборе «Что показывать».
- Экспорт в CSV (`путь;имя;дата;широта;долгота`, открывается в Excel), импорт из CSV/TXT (по пути «Папка/…/файл» или по уникальному имени файла).
- «Копировать в папку» — копирует файлы избранного в выбранную папку (Chrome/Edge на компьютере); при совпадении имён добавляется «(2)».

**Город и дата крупно** (флажок «Город и дата»): город определяется по геометке через [Nominatim](https://nominatim.org/) (OpenStreetMap). По [правилам сервиса](https://operations.osmfoundation.org/policies/nominatim/) — не чаще 1 запроса в секунду, результаты кэшируются (ячейка ≈ 1 км), так что повторные места сеть не трогают.

**Слайд-шоу — порядок**
- *По порядку*: папки идут в порядке списка; внутри папки сначала файлы, потом подпапки; имена сравниваются «естественно» (`IMG_2` < `IMG_10`).
- *Полностью случайно*: перемешивание без повторов; на каждом круге — новое.
- *Умный* (с тем же N): похожие кадры, снятые подряд (серия, бёрст, несколько дублей одного вида, RAW и его JPG), сворачиваются в один — самый резкий; серия стоит в показе на месте своего первого кадра. Дальше — **один проход вперёд** по уникальным кадрам со случайным шагом ≈ N: номер в показе, в наборе и в папке только растут; «По кругу» — новый проход с новым шагом. **N = 1 — все уникальные подряд.** Похожесть определяется по уменьшенной копии кадра (корреляция яркости 16×16) у кадров, снятых не дальше 3 минут друг от друга; резкость — по изображению 640 px. Ползунок «Похожесть» — от «почти одинаковые» до «просто похожие». Результаты анализа кэшируются. Видео всегда уникальны.
- *По порядку со случайным шагом (в среднем N)*: идём по списку вперёд, перескакивая через случайное число файлов. Шаг равномерно распределён на 1…2N−1, поэтому в среднем равен N (например 1, 10, 15, 23, 26…). Дойдя до конца списка, начинаем новый проход по ещё не показанным, и так пока не покажутся все. Затем начинается новый цикл. Внутри прохода хронология сохраняется. Последние проходы получаются короткими, потому что каждый берёт примерно 1/N от оставшегося.
- **Просмотр одного фото** («🔍 Открыть» на карте, щелчок по плитке в галерее): `↑/↓` листают соседние фото по **всем** папкам в порядке имён, таймера нет. Кнопка «▶ Слайд-шоу отсюда» (или `Пробел`) запускает слайд-шоу с этого фото по текущим настройкам набора и порядка.
- **Ручное листание**: выключите «Авто» — таймер остановится, листать `↑/↓`, кликом или колесом.
- Настройки набора (Отмеченные / Папка / На карте / Все), порядка, автосмены, интервала и подписи можно менять прямо в просмотре: кнопка ⚙ или клавиша `S`. Смена набора или порядка перестраивает показ с текущего фото (если его нет в новом наборе — с начала).
- **RAW ↔ JPG в просмотре**: если у фото есть связанный файл с тем же именем, вверху появляется кнопка «⇄ JPG» (или «⇄ RAW»), клавиша `J`: связанный файл показывается в уголке, щелчок по нему — перейти к нему (фильтры при этом сбрасываются). Опция «Значок RAW» — полупрозрачная пометка RAW в углу кадра.
- **Подпись** внизу: путь, дата съёмки, номер в показе, номер во всём наборе (по сортировке) и номер в исходной папке. **Крупно** — любой из номеров крупным шрифтом в выбранном углу (↖ ↗ ↙ ↘).
- **Метаданные** (опция «Метаданные» или клавиша `E`): полупрозрачная таблица — файл и разрешение, дата (с часовым поясом), камера, объектив, выдержка, диафрагма, ISO, фокусное (и эквивалент 35 мм), экспокоррекция, режим, замер, вспышка, баланс белого, координаты, высота, направление, город; остальные теги — списком «Все теги».
- RAW помечены значком «RAW» на миниатюрах карты и плитках галереи.
- **Масштаб и поворот** (только на экране, файл не меняется): `Ctrl`+колесо — увеличить вокруг курсора (щипок на тачпаде тоже работает), `Ctrl`+перетаскивание или просто перетаскивание увеличенного фото — двигать, `0` / двойной щелчок / `Esc` — сброс. `Ctrl+←/→` — поворот на 90°; поворот запоминается до перезагрузки страницы. Пока фото увеличено, автосмена стоит.
- Клавиши: `↑/↓` (или клик / колесо мыши) — назад/вперёд по порядку показа (подряд или случайно, по настройке); `←/→` — соседние фото **на карте**: → переходит к ближайшему ещё не показанному фото, ← возвращает назад по пройденному пути. Если карта ещё не построена, геометки ищутся автоматически. После такой «прогулки» `↓` и автопоказ продолжают слайд-шоу с текущего фото (если оно есть в наборе). `Пробел` — пауза, `+/−` — интервал, `I` — подпись, `G` — мини-карта, `M` — прервать показ и перейти к большой карте, `F` — полный экран, `Esc` — выход.

**Галерея (плитка)**
- Кнопка «▦ Галерея» открывает плитку миниатюр того же набора, что выбран для слайд-шоу. Размер плиток меняется ползунком; крупные плитки строятся из полного файла.
- Щелчок по плитке открывает просмотр с этого фото на паузе: стрелки листают, `Esc` возвращает в галерею. «▶ Слайд-шоу» запускает показ этого набора в выбранном порядке. 📍 на плитке переходит к фото на карте.
- С карты: кнопка ▭ — выделить область рамкой и открыть галерею по ней; ▦ — галерея всей видимой части карты; «▦ В галерее» — у группы фото из одной точки.

**Видео** (MP4, MOV, M4V, 3GP, WebM, MKV — по умолчанию **выключено**, включается чипом «Видео» в фильтре)
- В галерее — кадр из видео и длительность, на карте — если в ролике есть геометка (Android: атомы `©xyz`/`loci`, iPhone: `com.apple.quicktime.location.ISO6709`). Дата — из `creationdate` (iPhone) или `mvhd`.
- В слайд-шоу видео играет целиком (со звуком, если браузер разрешил), автосмена — после окончания ролика. Ролики, которые браузер не умеет воспроизводить (например, HEVC/H.265 без аппаратной поддержки), пропускаются с сообщением.
- С Яндекс.Диска видео воспроизводится по прямой ссылке, без загрузки в память.

**Фильтр**
- Фото / Видео и форматы фото: JPG / RAW / HEIC / другие (по расширению файла).
- По камере или телефону: модель берётся из EXIF (Make + Model), список с количеством фото строится после «Найти фото с геометками» или кнопки «обновить список». «Нет данных о камере» — фото без этих тегов (скриншоты, сохранённые из мессенджеров и т. п.).
- Фильтр действует на слайд-шоу, просмотр, галерею и карту и сохраняется между сеансами.

**Карта**
- «Найти фото с геометками» читает EXIF GPS. Результат кэшируется по ключу «путь + размер + дата изменения», поэтому повторное сканирование быстрое.
- Учитываются только отмеченные папки. RAW по умолчанию на карте не показываются (обычно они дублируют JPG) — флажок «RAW на карте». При снятии флажка фото пропадают с карты сразу, при установке карта тихо пересчитывается (из кэша это быстро).
- Карта на [MapLibre GL JS](https://maplibre.org/) (отрисовка через WebGL). Подложки: OpenStreetMap, [OpenFreeMap](https://openfreemap.org/) (векторная, без ключа), OpenTopoMap, спутник Esri.
- Одиночные фото показываются миниатюрами (встроенными в EXIF, если есть), близкие — объединяются в цветной кружок с числом. Щелчок по группе приближает карту. Если в группе фото из одной точки (серия кадров), открывается галерея этих фото. **Плотность** задаёт радиус группировки: от 3 размеров миниатюры (минимум) до 0,3 (максимум: больше отдельных фото, миниатюры могут частично перекрываться). **Группы**: кружки с числом или, при приближении (улицы / город / регион / всегда), миниатюра первого фото с числом. Размер миниатюр — ползунком в настройках (сохраняется) или кнопками ⊕/⊖ на карте (только до перезагрузки).
- Карточка фото: «🔍 Открыть» и «▶ Слайд-шоу отсюда». Если фото входит в набор прерванного слайд-шоу, показ продолжается по этому набору. Иначе используется набор, по которому построена карта.
- Во время показа: `G` — мини-карта, которая следует за текущим кадром; «Перейти к карте» прерывает показ, открывает карту на текущем фото, а там можно выбрать другое фото и продолжить с него.

**RAW**
- Поддерживаются CR2, CR3, CRW, NEF, NRW, ARW, SRF, SR2, DNG, RAF, ORF, RW2, RWL, PEF, SRW, X3F, 3FR, FFF, IIQ, ERF, KDC, MRW, MOS, MEF, GPR.
- **DNG с телефонов** (Xiaomi, Samsung, Pixel…) часто не содержат превью вовсе. Такие файлы PhotoViewer **проявляет сам** (`lib/rawdng.js`, в фоновом потоке): чёрный/белый уровни → коррекция виньетирования (GainMap) → бининг 2×2 (половинное разрешение, ≈ 2000×1500 для 12 Мп) → баланс белого → цветовая матрица камеры → автоэкспозиция и тональная кривая. Это быстрая упрощённая проявка (≈ 0,8 с на кадр), цвета и контраст — приблизительные. Поддерживаются DNG без сжатия; DNG со сжатием (lossless JPEG) — пока только если в них есть превью. Миниатюры RAW кэшируются в браузере.
- Для остальных RAW браузеры не умеют декодировать данные сенсора, поэтому показывается **встроенное JPEG-превью**, которое камера кладёт в файл. Из всех JPEG-потоков в файле берётся самый большой, а потоки, сжатые без потерь (это сами данные сенсора), пропускаются. У большинства камер превью полноразмерное или близкое к нему, но у части старых или бюджетных моделей оно меньше (например 1620×1080). Обработки RAW (баланс белого, экспозиция) нет: вы видите то, что показал бы экран камеры.
- Ориентация берётся из превью, а если её там нет, из RAW. Геометки и даты читаются из самого RAW (форматы на основе TIFF: CR2, NEF, ARW, DNG, PEF…). Для остальных (CR3, RAF…) они читаются из встроенного превью; если камера их туда не записала, их не будет.
- **RAW + JPG с одинаковым именем («двойники»)**: если в RAW нет геометки, даты или модели камеры, они берутся у JPG/HEIC с тем же именем — сначала из той же папки, иначе из любой подключённой (частая раскладка «RAW/ отдельно»; при одинаковых именах в разных местах берётся самая близкая по пути папка) — RAW появляется на карте; миниатюра RAW — из JPG; если RAW не удаётся показать, показывается JPG с пометкой. Работает и когда JPG скрыт фильтром.
- Если камера снимает RAW+JPEG, RAW по умолчанию пропускается, когда рядом есть JPEG/HEIC с тем же именем (настраивается флажком).
- Если в файле нечего показать, это запоминается до перезагрузки страницы — файл не перечитывается снова и снова.
- Чтобы найти превью, файл читается целиком, а это 20–80 МБ. С быстрого диска это доли секунды, по сети заметно дольше. Слайд-шоу заранее загружает следующий кадр.

## Запуск

Лучше всего работает в **Chrome или Edge**: им нужен [File System Access API](https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker) (`showDirectoryPicker`). С ним браузер выдаёт странице «ключ» к папке, который можно сохранить, и после перезагрузки папки остаются в списке.

**Совместимый режим** — это обычный HTML-выбор папки (`<input type="file" webkitdirectory>`). Он есть во всех настольных браузерах, но доступ не сохраняется: при выборе браузер один раз отдаёт список файлов, и после перезагрузки страницы папку надо выбрать заново. В браузерах без File System Access API (Firefox, Safari, Brave по умолчанию, некоторые сборки на Chromium) кнопка «+ Добавить папку» сама переключается в этот режим и показывает пояснение. Узнать, есть ли API в браузере: F12 → Console → `'showDirectoryPicker' in window`.

Варианты:
1. GitHub Pages: включите в Settings → Pages (ветка `main`, корень) и откройте `https://<user>.github.io/photoviewer/`. Файлы при этом всё равно не покидают компьютер.
2. Локально: `python -m http.server 8000` в папке репозитория, затем откройте `http://localhost:8000/`.
3. Двойной клик по `index.html` (`file://`) тоже должен работать в Chrome/Edge, но этот вариант менее проверен (см. ниже).

Библиотеки лежат в папке `lib/`: MapLibre GL JS 5.24.1 (BSD-3) и exifr 7.1.3 (MIT), их лицензии лежат рядом. `lib/rawdng.js` и `lib/rawworker.js` — собственный код проявки DNG. Интернет нужен только для подложки карты.

## Android и Android TV (APK)

Тот же PhotoViewer, упакованный в приложение (Capacitor) — работает без ПК, в том числе с **флешкой** на приставке.

- **Скачать**: <https://knvspb.github.io/PhotoViewer/apk.html> (перенаправляет на последнюю сборку в релизе [android-latest](https://github.com/knvspb/photoviewer/releases/tag/android-latest)). На Android TV удобно через приложение «Downloader»: ввести адрес `knvspb.github.io/PhotoViewer/apk.html`. Нужно разрешить установку из неизвестных источников.
- **Папки и флешки**: «+ Папка» открывает системный выбор папки Android (SAF); доступ запоминается. Для EXIF и миниатюр читается только начало файла, видео играет потоком с перемоткой.
- **Яндекс.Диск**: вход открывается внутри приложения (можно войти по QR-коду через приложение Яндекса на телефоне), токен возвращается в приложение автоматически.
- **Пульт**: стрелки — перемещение по кнопкам и плиткам (фокус подсвечен жёлтым), OK — нажать / пауза / «слайд-шоу отсюда», «Назад» — закрыть просмотр/галерею/окно, кнопка «Меню» (≡) в просмотре — настройки показа. В браузере режим пульта включается добавлением `?tv` к адресу.
- APK собирается автоматически GitHub Actions (`.github/workflows/android.yml`) при каждом изменении в `main`. Подписан постоянным отладочным ключом из репозитория (`android-app/android/app/photoviewer-debug.keystore`), чтобы обновления ставились поверх; для публикации в Google Play нужен отдельный приватный ключ.

## Ограничения

- HEIC/HEIF (iPhone): браузеры на Windows не умеют их показывать, поэтому слайд-шоу такие файлы пропускает. Геометки из них при этом читаются и на карте видны.
- Сортировка `Intl.Collator({numeric:true})` близка к сортировке Проводника (`StrCmpLogicalW`), но не идентична ей в экзотических случаях.
- Фото, которые намного больше экрана, для показа заранее уменьшаются до размера экрана (меньше памяти, нет артефактов масштабирования); при увеличении `Ctrl`+колесом подставляется оригинал.
- Карте нужен WebGL. Он есть во всех современных браузерах, но может быть отключён политикой или старыми драйверами видеокарты.
- Тайлы OpenStreetMap подчиняются [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/). Браузер со страницы `file://` не отправляет заголовок Referer, и OSM может такие запросы ограничивать. В таком случае используйте вариант 1 или 2 либо другую подложку.
